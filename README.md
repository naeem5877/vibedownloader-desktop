## 📥 Install

Download the installer for your system from the [**Releases page**](https://github.com/naeem5877/vibedownloader-desktop/releases/latest), then follow the matching guide.

| System | Download | Guide |
| --- | --- | --- |
| 💻 **Windows** | `.exe` installer | [Windows →](#install-windows) |
| 🍎 **macOS** | `.dmg` | [macOS →](#install-macos) |
| 🐧 **Linux** | `.AppImage` or `.deb` | [Linux →](#install-linux) |
| 📱 **Android** | `.apk` | [Android →](#android) |

> **First launch:** VibeDownloader sets up its downloader (yt-dlp) by itself. If FFmpeg isn't already on your computer, it downloads one once (about 190 MB). If you already have FFmpeg, it is used as is.

<a id="install-windows"></a>

### 💻 Windows

1. Run the downloaded **`.exe`** and follow the setup wizard.
2. Open **VibeDownloader** from the Start Menu.

---

<a id="install-macos"></a>

### 🍎 macOS

1. Open the downloaded **`.dmg`**.
2. Drag **VibeDownloader** into **Applications**.
3. Open it from Applications.

> **⚠️ "VibeDownloader is damaged and can't be opened"?**
> Expected: the app isn't signed with an Apple Developer ID yet ($99/year). Run this **once** in Terminal, then open the app normally:
>
> ```bash
> xattr -c /Applications/VibeDownloader.app
> ```
>
> It only removes macOS quarantine flags, and the code is fully open source if you'd like to inspect it first.

---

<a id="install-linux"></a>

### 🐧 Linux

**AppImage** (most distributions)

```bash
chmod +x VibeDownloader-*.AppImage
./VibeDownloader-*.AppImage
```

**Debian / Ubuntu** (`.deb`)

```bash
sudo dpkg -i VibeDownloader-*.deb
```

## 🛟 Help & Setup

<a id="cookies"></a>

### 🍪 Cookies (Optional)

Some content needs a signed-in session, such as age-restricted videos or private accounts. You can add your cookies for a platform in the app.

- Cookies are stored **only on your computer** and are used only to authenticate your own downloads
- They are never uploaded to any server
- **Tip:** for the most reliable result, export your cookies from a **private/incognito window**, then close that window right away. A browser session that stays open can rotate its cookies and make the exported ones stop working.

<a id="troubleshooting"></a>

### 🧰 Troubleshooting

<details>
<summary><b>A download fails, or only low qualities show up</b></summary>

<br />

1. Open **Settings** and make sure the downloader (yt-dlp) is up to date
2. Try again without cookies, or with freshly exported cookies
3. Turn off any VPN. Some VPN and shared IPs are blocked by YouTube
4. If it still fails, open a [new issue](https://github.com/naeem5877/vibedownloader-desktop/issues) with the video link (a public one), your app version, and your OS

</details>

<details>
<summary><b>"FFmpeg could not be downloaded", or video and audio processing doesn't work</b></summary>

<br />

VibeDownloader uses the FFmpeg already on your computer when it has a complete one, and otherwise downloads its own copy once (about 190 MB). If that download is blocked by your network, firewall or antivirus, install FFmpeg yourself, then **restart VibeDownloader**:

```bash
# Windows
winget install Gyan.FFmpeg

# macOS
brew install ffmpeg

# Debian / Ubuntu
sudo apt install ffmpeg
```

On Linux, avoid the Snap package of FFmpeg. Snap blocks it from reading the app's files, so VibeDownloader skips it.

</details>

<details>
<summary><b>The extension button doesn't show up</b></summary>

<br />

Reload the extension on your browser's extensions page, then refresh the site's tab. If it still doesn't appear, check that the desktop app is installed and was opened at least once so the local connection is registered.

</details>

<a id="faq"></a>

### ❓ FAQ

<details>
<summary><b>Is VibeDownloader free and safe?</b></summary>

<br />

Yes. It is free, ad-free and open source under GPL v3.0, so you can read every line. Downloads and cookies stay on your device.

</details>

<details>
<summary><b>Which sites can I download from?</b></summary>

<br />

YouTube, YouTube Music, Spotify, Instagram, TikTok, Facebook, X (Twitter), Twitch, Pinterest and SoundCloud. See [Supported Platforms](#platforms).

</details>

<details>
<summary><b>Where do my downloads go?</b></summary>

<br />

Into a **VibeDownloader** folder inside your Downloads folder, sorted by platform and type (for example `YouTube/Videos` or `Spotify/Music`). You can change the location in **Settings**, and everything shows up in the Library.

</details>

<details>
<summary><b>Do I need to install FFmpeg?</b></summary>

<br />

No. If your computer already has a complete FFmpeg, VibeDownloader uses it. If not, it downloads its own copy once, the first time you need it.

</details>

<details>
<summary><b>Is there a version for Adobe Premiere Pro?</b></summary>

<br />

Yes. [Vibe Plugin](https://github.com/naeem5877/vibe-plugin) is a free panel that downloads into your project bin or timeline. See [For Editors](#premiere-plugin).

</details>

<details>
<summary><b>Can I download a whole YouTube playlist, or just a clip?</b></summary>

<br />

Both. Paste a playlist link to queue it, or use **Cut & Download** to save only the part you want.

</details>

<details>
<summary><b>Can it save MP3, WAV or high-quality audio?</b></summary>

<br />

Yes. Save audio as MP3 or WAV, and Spotify tracks in up to lossless and hi-res formats, with cover art and tags embedded.

</details>

<details>
<summary><b>Why do my downloaded videos play in QuickTime, VLC and editors?</b></summary>

<br />

Files are checked and, only when needed, converted to H.264 + AAC. A GPU is used automatically when it is faster.

</details>

<a id="privacy"></a>

### 🔐 Privacy

- Downloads, conversions and cookies are processed **locally on your device**
- No accounts, no ads
- **Crash and error reports:** VibeDownloader uses [Sentry](https://sentry.io) to find and fix bugs. Links and file paths are scrubbed before anything is sent, and cookies are never included
- You can read exactly what is collected in this repository — the app is fully open source

# Clone the repository

# Build for Windows
